# AGENTS.md — Analysis Engine

Scope: `src/analyzer/`. Root [`AGENTS.md`](../../AGENTS.md) is canonical.

`analysis_engine.py` runs four passes: calculation → pattern detection → chart render → LLM synthesis (multimodal; the default Google model is `gemini-3.8-flash`, the live deployment runs `opencode`). The only place turning OHLCV into the dict the brain and strategy consume.

## Inputs

- `DataFetcher` (CCXT): `ohlcv_data: np.ndarray` (timestamp, OHLC, volume) on the configured frame, plus 365 daily and 300 weekly; order-book depth (buckets, near-mid liquidity, largest wall) and trade flow (size distribution, buy/sell ratio).
- CoinGecko, Alternative.me (Fear & Greed), DeFiLlama (via RAG), RAG news block, brain context.
- Config: `crypto_pair` (BTC/USDC in the example config), configured `timeframe` (4h in the example config), 999 candles, `AI_CHART_CANDLE_LIMIT = 125`.

### Social sentiment context

- `SocialSentimentAnalyst.fetch_posts()` reads one StockTwits symbol stream (`api.stocktwits.com/api/2/streams/symbol/{symbol}.json`, symbol derived from `crypto_pair` as `BASE.X`) — no LLM call, no API key, no embedding/index dependency. Reddit was the previous source and is gone: it retired the public Atom feeds on 2026-11-13 and now answers `404` (RSS), `403 Blocked` (`.json`) and a login redirect (HTML) to every anonymous client, from any IP, with app creation behind manual approval. `build_context()` supplies ≤15 distinct messages from the last 48h, ≤600 estimated tokens including instructions and UTC dates; bodies under 20 characters, undated/future messages and duplicates excluded, bodies never truncated to fit. Messages are untrusted evidence: interpret price expectations for the traded asset, respect negation, keep wallet-security concerns apart from price outlook.
- `analysis.social_sentiment` = `outlook` (BULLISH/BEARISH/MIXED/INSUFFICIENT_EVIDENCE), `evidence` (distinct supplied message IDs), `reason` (1–240 chars; an over-long reason is clamped at a word boundary, never a reason to discard the assessment). No eligible messages → null; malformed or out-of-sample assessments discarded, never replaced by a keyword verdict.
- The outlook lands in `MarketConditions.social_sentiment` for entry-time learning; missing stays empty, insufficient evidence is never directional. Keyword scoring and placeholder vote/comment counts stay deleted.
- A repeated identical fetch failure is logged once (WARNING) and then at DEBUG until it changes; recovery is logged at INFO. One refresh every 30 minutes, at most two request attempts inside it; only the very first cycle can wait for the first sample, up to `SOCIAL_FIRST_SAMPLE_TIMEOUT` (180 s), and a later cycle reads the cached sample.
- The stream sits behind Cloudflare and the client matters: `aiohttp`, `httpx` and `urllib` all answer **403 "Just a moment..."** with any header set (measured 2026-11-18: urllib passed 3/3 at 02:56 and failed 8/8 at 05:14), while `curl.exe` answered **200 ten times out of ten** over the same window. The fetch therefore shells out to curl in a worker thread; do not "simplify" it back to a Python HTTP client. The binary is resolved once in `start.py` and a missing one is reported at startup, so keep the transport on the injected path. A 403 is retried once after 5 s, a 429 after `Retry-After` (seconds or an HTTP date), capped at 120 s; the retry budget never sleeps after its last attempt.

### RAG and brain handoff

- `analyze_market` clears `PromptBuilder.custom_instructions` in its `finally` block — failed, cancelled and early-returned requests included — so a fresh RAG snapshot never retains the previous cycle's. Keep HOLD/error results and cancellation propagation; no repair model calls.
- Brain: `brain_service.get_context()` + `brain_service.get_dynamic_thresholds()`. Whole-prompt preflight uses the configurable estimated-token ceiling; provider-bound checks (`managers/AGENTS.md`) also cover the model plus output/image/safety reserves. The provider-bound `Full prompt content` record (terminal and `Bot.log`, tagged `skip_live_stream`) proves what was sent; the dashboard live console omits it because Last Prompt shows the exchange from engine state.

## Output

`analyze_market()` → `analysis` (signal, confidence 0–100, trend direction + `strength_primary`), `raw_response`, `technical_data`, `sentiment`, `market_microstructure` (delta vs previous snapshot, per symbol), `chart_analysis`, `prompt_metadata`, `prompt_lint`. `strength_primary` is the ADX of the configured analysis frame; `strength_4h` is accepted only as a legacy input alias.

Deterministic validators overwrite LLM claims: `TrendValidator` (ADX claims cross-checked at a 15-point warning, the computed value always wins without changing the signal — the prompt copies ADX readings, never a subjective strength score); `PatternQualityScorer` (0–100 from 30% quantity, 30% confirmation, 20% recency, 20% indicator alignment; >25-point divergence from the LLM is flagged and overwritten); `RiskRewardValidator` (entry/SL/TP and `RR_CHECK` narrative examples recomputed with the same Numba arithmetic as `RiskManager`; an inconsistent entry becomes HOLD before strategy and executor, the correction is written into `raw_response` for the next cycle's `## PREVIOUS ANALYSIS CONTEXT`; JSON-object and narrative+fenced-JSON replies both handled; execution still recomputes final R/R after SL/TP normalization).

`DecisionGate` (`decision_gate.py`, optional, `mode = off` by default) asks a second model one Decisions record after those validators and before `_format_analysis_response` renders `raw_response`: a `score` for the entry location, a `choice` for the next three candles and the `edge_now.noul` bit (positive expectancy after costs), fed a compact state — the decision without its `confidence`, the entry indicators, the last 20 candles and the `direction / regime / ADX bucket` triple the brain's rules declare. It may only shrink `position_size` (score 0–1 → 0.5, 2 → 0.75, 3 → 1.0, a disagreeing direction ×0.75, floor 0.5, never above 1.0) and only in `mode = size`; `shadow` makes the same call, journals it and leaves the decision byte-identical, so the mode that touches size has to earn it from the journal. A refusal, timeout or malformed body is one warning and an untouched decision. Every call appends one line to `data/trading/decisions_gate.jsonl`; the gate never writes to the brain store, the statistics or the intent journal.

## Prompt

`PromptBuilder` order: trading context (pair, timeframe, position, performance) → market data → technicals → period metrics (1D–30D, volatility, S/R) → indicators delta → macro (daily SMA sets, 200W methodology, golden/death crosses) → sentiment → brain context → previous analysis → RAG.

Brain section: calibration per level, direction bias with `LIMITED DATA`, blocked-trade feedback (`get_blocked_trade_feedback()`, 168h, as `## CRITICAL FEEDBACK: System Rejections` with R/R gap, SL/TP detail, pre-flight checklist), top-3 similar experiences, CoT Step 6, rules matched to conditions (similarity %, freshness, evidence score), recent post-mortems.

Every config-derived sentence renders the value the runtime enforces: the analysis frame from `Config.TIMEFRAME`, the position caps from `RegimeRiskProfileSelector.effective_caps(MAX_POSITION_SIZE)`, the decision thresholds from `src/trading/threshold_defaults.py`. A failed frame lookup raises (`TemplateManager._timeframe_minutes`, `PromptBuilder` normalises at construction); the style block and the relevance window never fall back to 60/120 minutes. The render tests in `tests/domain_infra/test_config_propagation.py` and `tests/domain_brain/test_prompt_template.py` are the gates for this prose.

`## PREVIOUS ANALYSIS CONTEXT` (only with a previous response): decision snapshot (signal, confidence, entry/SL/TP/R:R, size), reasoning with JSON/schema/instruction artifacts stripped and **no separate length cap**, a time check against current data, and after a strategy veto the patched `signal: "HOLD"` with `⚠️ REJECTED` instead of a misleading BUY.

- EV framework: live capital + fee model; a positive rolling inference cost adds the cost line, subtracts it in step 5 and raises the 1.5× threshold to fees + inference. With no measured cost the block is byte-identical to the fee-only version.
- `model_verbosity` targets: low 400, medium 1000, high 2000, full 8000 (default) output tokens, excluding hidden reasoning and decision JSON; never alters execution fields or provider caps.
- `full` uses Markdown research sections, but `11) RISK/REWARD:`, `12) DECISION:` and `13) EXECUTION NOTE:` stay unheaded at column zero for the Python validator. Never copy fabricated analogues or probabilities from a reference report.
- DeepSeek returns one JSON object with a Markdown `narrative`; other providers return narrative plus a trailing JSON block; the shared result processor renders both.
- Previous reasoning prefers the structured thesis, else the sanitized narrative, untruncated. `PromptBudgetPolicy` checks the whole request before every provider/model call, fallbacks included; it may omit optional previous analysis, but a section holding Python R/R feedback is protected — if protected content cannot fit, refuse the request. Local cl100k counts are estimates; response validation is not a context-length guard.
- User turn: concise JSON instruction plus optional 1920×1080 PNG chart (4-row). `<think>…</think>` is stripped by `AnalysisResultProcessor._clean_response()` before parsing. `UnifiedParser` tries a ```json block → `json.JSONDecoder.raw_decode()` → HOLD fallback; `TradingAnalysisResponseModel` validates into `TradingAnalysisModel`; BUY/SELL requires `entry_price`, `stop_loss`, `take_profit`, `risk_reward_ratio`, `position_size`.

## Pattern engine

`TechnicalCalculator` (`technical_calculator.py`) refreshes 40+ arrays per cycle (volume, momentum, volatility, trend, S/R, statistics); weekly macro scores five 200W-SMA criteria for cycle-phase confidence. `PatternAnalyzer` (`pattern_analyzer.py`) orchestrates **indicator** patterns only, delegating to `IndicatorPatternEngine` (`pattern_engine/indicator_patterns/indicator_pattern_engine.py`); chart patterns are read visually by the LLM. All detection is `@njit(cache=True)`. Seven categories: RSI (oversold/overbought, W-bottom, M-top), MACD (crossovers, histogram), divergence (5-bar min spacing), volume (spike, climax, dry-up, accumulation/distribution), Stochastic (20/80, crosses inside 30/70), MA crossovers, volatility (ATR spike, BB squeeze, TTM squeeze).

- BB squeeze (`volatility_patterns.py`) compares width against the lowest 20% of the last **120** bars and reports `width_percentile` (share of the window narrower than now); the engine sets `confidence = 100 - width_percentile`. Both are window-relative, never a scaled price width. A 20-bar window is wrong — it fires on noise.
- TTM squeeze is Carter's pairing: BB(20, 2σ) vs KC(20, **1.5 × Wilder ATR**), built once in `TechnicalCalculator._calculate_volatility_indicators` (`keltner_channels(length=20, multiplier=1.5, atr_mamode="rma")`) and reused for the prompt's `KC: U/M/L` line — never a second channel definition. A 2.0 × ATR channel is the loose Squeeze Pro tier and must never be labelled extreme volatility.
- The squeeze is a **state, not an event**: `detect_keltner_squeeze_numba` returns `(in_squeeze, bars_in_squeeze, bars_since_release)`; the engine emits `ttm_squeeze` with its run length (`in compression for 3 bars`) while inside and `ttm_squeeze_fired` once released — a multi-day compression must not look like a fresh setup.
- Every state pattern reports duration: `macd_histogram_trend_streak_numba`, `volatility_trend_streak_numba`, `bb_squeeze_streak_numba`, `accumulation_distribution_streak_numba` count consecutive bars by re-evaluating the owning detector's rule through a shared `_*_at` helper (label and streak cannot drift); the engine renders `for N bars`. Without a duration the model reads an old condition as a fresh signal.
- No grading adjectives: "momentum shift", "breakout imminent", "strong signal" claim more than a relative threshold proves.
- `## Key Terminology` (`prompts/template_manager.py`) is the single home for provenance and thresholds: RSI 14 Wilder, MACD 12/26/9 EMA, Stochastic 14/3/3, Bollinger 20/2 population σ, ATR 20 Wilder, KC EMA(20) ± 1.5 × Wilder ATR(20), RSI 30/70, Stochastic 20/80, volume spike 2.5× / dry-up 0.5× / climax 3×, ATR spike 1.5×, BB squeeze lowest 20% of 120 bars, MACD histogram majority of 3 changes, volatility trend 6 of 9 ATR changes, A/D 60%/40% (`strength = |share − 0.5| × 2`), volume-price divergence ±2%/−15%, divergence spacing 5 bars. A new indicator or threshold needs a legend line, or the model assumes textbook defaults.

`ChartGenerator` (`pattern_engine/chart_generator.py`): 1920×1080 PNG (Plotly → Playwright's bundled Chromium), rows candles+SMA 55% / RSI 15% / volume 15% / CMF+OBV 15%, black background, high contrast, swing and max/min annotations; 30s export timeout, 3 attempts (2 retries) with backoff, daemon thread. `_render_with_playwright` writes `fig.to_html` into a headless page and screenshots `.main-svg`; it needs `playwright` plus `python -m playwright install chromium` (the launcher installs the browser when it is missing). Kaleido is not used: on this box it could not drive any tested Chrome (CHANGELOG 2026-10-27), and the system Chrome is not a chart dependency. A missing browser or a failed render logs the error and degrades to text-only.

`temperature`/`top_p` are loaded from `config.ini [model_config]`, never hardcoded; `frequency_penalty`/`presence_penalty` fall back to `freq_penalty`/`pres_penalty`; `max_tokens` and `google_max_tokens` are both **required**; `google_thinking_level` defaults `high`, `google_code_execution` `false`. Unsupported-by-provider keys are dropped by the shared retry path (`managers/AGENTS.md`).

## Degradation

Fetch failure → `{"error": "Failed to collect market data", "recommendation": "HOLD"}`. Unsupported configured or overridden timeframe → `ValueError` at the engine boundary; the collector requires a frame and refuses to fetch without one; period metrics refuse a frame they cannot convert (`"1D"` is not 24 candles by default). New token/thin history → `is_new_token` + macro defaults. Chart failure or hang → text-only. RAG missing → empty context. Unparseable response → HOLD with raw text; missing BUY/SELL fields → `ValueError`. Incomplete last candle dropped; array mismatches sliced to the rendered count.
