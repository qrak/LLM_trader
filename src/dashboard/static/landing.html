🧠 Core Features

Not just another trading bot. This one reasons, debates, remembers, and improves.

🤖

LLM Chart Reading

Google Gemini 3.6 Flash reads candlestick charts visually AND numerically — interpreting 50+ indicators simultaneously, spotting patterns a human would miss.

⚔️

Bull vs Bear Internal Debate

Before every decision, the LLM argues BOTH sides. Bull case optimistic, Bear case pessimistic. Then it decides. More balanced, less emotional.

🧬

Vector Memory (ChromaDB)

Every closed trade is embedded as a vector. On the next cycle, the bot queries its own brain: "Have I seen this pattern before? What happened?"

🎯

Risk Profile Selector

Three dynamic modes — Aggressive, Conservative, Neutral. Switches automatically based on win rate, avg PnL, and market trend (ADX).

📰

Zero-Cost Sentiment

Reddit (r/CryptoCurrency, r/Bitcoin) and X/Twitter (via Nitter) scraped directly — free JSON feeds. No API keys. Plus RSS from CoinDesk, CoinTelegraph, Decrypt.

🛡️

Execution Safeguards

Cooldown windows prevent overtrading. Max position size enforced. Symbol whitelist. SL/TP validated against ATR. Paper trading by default.

🔍

AST Codebase Vector Search

Natural-language semantic search across 160+ Python files and docs via ChromaDB (scripts/query_codebase.py). Finds exact symbols, functions, and architecture patterns instantly.

📐

768D Vector Memory Engine

Powered by BAAI/bge-base-en-v1.5 high-dimensional embeddings. Retains trade experiences, semantic rules, surprise ratio annotations, and confidence stats across trading sessions.

🔮

Adversarial Awareness

The system prompt teaches the LLM about real order books — counterparty orders, funding rate traps, liquidity squeezes. Not just abstract lines on a chart.

📊

Real-Time Dashboard

WebSocket-powered live UI with ApexCharts candlesticks, Vis.js decision graphs, FTS5 trade journal search, and full prompt/response transparency.

📚 Research-Backed. Competitor-Aware.

This bot doesn't exist in a vacuum. It merges the best ideas from academic papers and open-source frameworks into a single, battle-tested trading engine.

TradingAgents (UCLA/MIT)

Multi-agent stock trading framework with bull/bear debate. Great design, but: stocks only, no crypto, no chart vision, no vector memory, no self-learning rules. We took their debate idea and ran with it — for crypto, with vision, with memory.

Optiver Research (2026)

LLMs pass the intern exam but fail at EV maximization and multi-step reasoning. Our fix: EV Framework that computes expected value from real trade history, adversarial awareness prompt, and a falsification check that rejects signals the LLM can't defend.

Agentic Trading Survey (arXiv 2026)

77 studies reviewed. Only 2 had proper time-consistent splits. Reproducibility: R0 (none). We hit R2: fully mocked test suite with 1,324 tests, deterministic output, CI-ready. All LLM responses validated before execution.

Lopez-Lira (Bank of Finland)

LLMs trade but don't care about money unless explicitly instructed. Our approach: risk profiles with real P&L feedback, post-mortem AI analysis of every closed trade, and a ChromaDB memory that literally shows the bot its past mistakes.
